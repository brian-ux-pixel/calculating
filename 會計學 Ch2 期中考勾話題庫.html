Exercises 2-2

會計恆等式缺額計算 (Accounting Equation Missing Amounts)

課本原文： Compute the missing amounts for the following three companies.
核心觀念： $\text{Total Assets} = \text{Total Liabilities} + \text{Equity}$。其中資產項目包含 Cash、Accounts Receivable、Land；負債包含 Accounts Payable、Mortgage Payable。

科目項目 (Account Items) Johnson Company Best Company Coury Company
Cash (現金) [資產] $11,500 $5,800 $17,000
Accounts receivable (應收帳款) [資產] 5,500 11,000 11,750
Land (土地) [資產] 48,500 41,000
總資產合計 (Total Assets) $65,500 - $69,750
Accounts payable (應付帳款) [負債] 3,500 16,000
Mortgage payable (抵押借款) [負債] 37,500 19,000 32,250
Equity (權益) [權益] 22,000 14,500
【E2-2 計算步驟詳解】

1. Johnson Co. 應付帳款 (A/P)：總資產 = $11,500 + 5,500 + 48,500 = $65,500。依恆等式 $65,500 = \text{A/P} + 37,500 + 22,000 \Rightarrow \mathbf{\text{A/P} = \$6,000}$

2. Best Co. 土地 (Land)：負債加權益 = 3,500 + 19,000 + 14,500 = $37,000（等於總資產）。土地 = $37,000 - 5,800 - 11,000 = \mathbf{\$20,200}$

3. Coury Co. 權益 (Equity)：總資產 = 17,000 + 11,750 + 41,000 = $69,750。負債 = 16,000 + 32,250 = $48,250。權益 = $69,750 - 48,250 = \mathbf{\$21,500}$

Exercises 2-5

權益要素倒推（保留盈餘與營業收入）(Computing Elements of Equity)

課本數據：
• 1月1日：Current assets $15,000 | Other assets $240,000 | Liabilities $125,000 | Capital stock $70,000 | Retained earnings $60,000
• 12月31日：Current assets $25,000 | Other assets $220,000 | Liabilities $85,000 | Capital stock increased by $20,000
• 本期發生：Expenses = $55,000；Dividends paid = $9,000。

先算 12/31 總資產與總負債，利用資產負債恆等式求出：

利用：期初 R/E + Revenues - Expenses - Dividends = 期末 R/E：

【E2-5 標準解析】

1. 期末總資產 = 25,000 + 220,000 = $245,000。期末負債 = $85,000。期末股本 = 70,000 + 20,000 = $90,000。
因此：$245,000 = 85,000 + 90,000 + \text{Ending R/E} \Rightarrow \mathbf{\text{Ending R/E} = \$70,000}$

2. 營業收入：60,000 + Revenues - 55,000 - 9,000 = 70,000 $\Rightarrow$ Revenues - 4,000 = 70,000 $\Rightarrow \mathbf{\text{Revenues} = \$74,000}$

資產負債表與損益表之勾稽連動 (Financial Statement Articulation)

Omni Company 數據：
• 1月1日：資產 $103,000，負債 $72,000 ➔ 期初權益 = $31,000
• 12月31日：資產 $167,000，負債 $88,000 ➔ 期末權益 = $79,000
• 全年權益淨增加 = $79,000 - $31,000 = $48,000！請在以下三種獨立情況下計算 2022 年之「淨利 (Net Income)」：

情況 1：發放現金股利 $12,100，無增資發行股票。

權益增量 $48,000 = 淨利 - 股利 $12,100

情況 2：增資發行股票 $18,000，無發放股利。

權益增量 $48,000 = 增資 $18,000 + 淨利

情況 3：增資發行股票 $72,000，且發放股利 $12,400。

權益增量 $48,000 = 增資 $72,000 - 股利 $12,400 + 淨利 (若為淨損請填負數)

Problem 2-1 (期中高分必考)

Stoker Co. 分類資產負債表要素計算 (Classified Balance Sheet)

課本必考手寫大題：請將科目區分為「流動」與「非流動」，並計算出缺漏的現金與五大分類總額。

Land: $312,000
Buildings: $337,500
Equipment: $322,500
Accounts Receivable: $178,500
Accounts Payable: $151,500
Notes Payable (short-term): $147,000
Mortgage Payable: $379,500
Capital Stock: $300,000
Retained Earnings: $279,000
Cash: ? (需透過資產負債恆等式倒推求得)

Cash (?) + Accounts Receivable

Land + Buildings + Equipment

Accounts Payable + Short-term Notes

Mortgage Payable (長期抵押貸款)

Capital Stock + Retained Earnings

總負債 + 總權益 - 其他已知資產

【P2-1 滿分作答解析】

• 非流動資產 = 312,000 (Land) + 337,500 (Buildings) + 322,500 (Equipment) = $972,000

• 流動負債 = 151,500 (A/P) + 147,000 (Short-term Note) = $298,500

• 非流動負債 = $379,500 (Mortgage Payable)

• 權益總計 = 300,000 (Capital Stock) + 279,000 (Retained Earnings) = $579,000

• 總負債與權益 = 298,500 + 379,500 + 579,000 = $1,257,000（等於總資產）

• 倒推現金 (Cash) = $1,257,000 - $972,000 - $178,500 (A/R) = $106,500

• 流動資產 = 106,500 (Cash) + 178,500 (A/R) = $285,000

Chapter 2 財務報表四大核心勾稽公式

1. 資產負債表恆等式 (Balance Sheet Equation)

$$\text{Total Assets} = \text{Total Liabilities} + \text{Total Equity}$$

流動資產 + 非流動資產 = 流動負債 + 非流動負債 + 股本 + 保留盈餘

2. 保留盈餘變動方程式 (Retained Earnings Articulation)

$$\text{Ending R/E} = \text{Beginning R/E} + \text{Net Income} - \text{Dividends}$$

3. 綜合損益表與每股盈餘 (Comprehensive Income & EPS)

$$\text{Net Income} = \text{Revenues} - \text{Expenses} - \text{Income Tax}$$

$$\text{EPS} = \frac{\text{Net Income}}{\text{Weighted Average Common Shares}}$$
